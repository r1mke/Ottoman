# ottoman_core

Zajednički Flutter paket za desktop i mobilnu aplikaciju: HTTP klijent s osvježavanjem tokena, modeli i API klase, kontroler prijave, košarica, lokalizacija (bs/en), teme i zajednički widgeti (slike, ocjene, profil, recenzije).

Nema vlastitog ekrana; koriste ga `ottoman_desktop` i `ottoman_mobile`. Testovi: `flutter test`.
